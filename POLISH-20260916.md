# Scrollworld polish

## Current implementation

- `assets/mechanical-companion-pixel-v2.png` is the active transparent pixel-art atlas. It preserves the silver/white mechanical canine, graphite joints and cyan accents. Generated from the previous dog artwork with the existing avatar as style reference. The previous realistic atlas remains available but is no longer rendered.
- `companion.js` registers all twelve frames, masks neighbouring atlas fragments, keeps dog scale consistent across poses and disables interpolation to match the avatar's crisp edges.
- The train actor reaches the actual last carriage centre and immediately begins a forward arc at chapter progress 0.745. It reaches the hole at 0.90, then descends. Mobile train travel leaves room for this forward exit. Companion follows the same feet trajectory.
- Chapter holes expand with actor scale. Train hole position leaves room for the whole opening.
- Rope uses two layers sharing the current avatar hand position: horizontal/reel-side run on scenery before the reel, vertical pull segment on foreground above the avatar. Avatar pose updates before either rope layer to avoid a one-frame mismatch. Router nodes paint after all connector paths and packets.
- `pacing.js` routes keys and trackpad gestures through one frame controller. Approved keyboard speeds remain ten seconds per chapter, eighteen seconds for chapter 01. Small and decreasing wheel events are accepted; magnitude and event count cannot accelerate travel. A 72 ms event gap marks gesture inactivity, without accumulated distance or a long-running target. Touch release, key release and blur stop their input. Navigation seeks immediately. Reduced-motion preference preserves native scrolling; scrollbar dragging remains direct navigation.
- `mascot.js` owns companion interaction: fixed 0.60 avatar height ratio, breathing, walking legs, sitting after five seconds idle, hover/focus forms, and reversible nine-panel mechanical assembly. Movement facing follows actual displacement for both actors, including reverse scroll. The walking cycle itself always advances forward.
- Five existing generated sheets are registered as 80 unique sprites. Every mapped scene item has a specific form (see `MASCOT-MAPPING.md`). No additional image generation is needed. `mascot-crops.js` registers isolated transparent cells; `work/prepare-mascot-atlases.py` preserves source artwork while masking baked checkerboard backgrounds.

## Verification

- JavaScript syntax checks pass.
- `node work/pacing-check.cjs` passes 480 keyboard/trackpad parity cases across all eight scroll chapters, 30/60/120 Hz frames, event intervals from 8 to 60 ms, and tiny, large and diminishing deltas. It also verifies bounded stop detection, no accumulated burst distance, reversal, touch/key release, blur and pinch-zoom bypass. These are simulated-input tests, not physical-trackpad verification.
- `node work/polish-unit-check.cjs` passes 162 scene samples at 1440×900 and 390×844 with mocked DOM/canvas. Checks include train continuity, forward jump, landing height, portal width, connector drawing order, and equal scroll displacement for deltas 1, 100 and 5000.
- Transparent RGBA output confirmed. Sprite exclusion regions remove zero opaque pixels belonging to their intended sprites.
- Browser verification remains incomplete: headless browser startup was blocked by the sandbox; the escalation request was declined. Do not describe the mocked checks as visual browser verification. `work/polish-check.cjs` is available for a future authorized browser run.
